# Superseded material

This directory holds one file: `pbpk_evaluation_analysis/pbpk_physchem_mechanistic_master.csv`,
the compound-level table that accompanied the earlier version of this work. It is kept because the
Data S3 data dictionary cites this path as the archive of that table.

Its values are superseded by `data/S3 pbpk mechanistic master.csv`, which is what the paper reports
and what the analysis pipeline builds. The dictionary in `data/S3 data dictionary.md` lists the
differences column by column. Use the Data S3 file; this one is here so the citation resolves.
